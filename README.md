# Instagram Tech News Automation

Automated pipeline that converts daily tech news into Instagram-ready carousel content.

## Features

- Fetches news from TechCrunch and Ars Technica
- Deduplicates and ranks articles
- AI-powered summarization
- Carousel slide generation
- Caption generation
- Canva CSV export for bulk design creation
- Quality validation and logging

## Workflow

News RSS → AI Summary → Carousel Text → Canva CSV → Canva Bulk Create → Instagram Post

## Tech Stack

- Python
- RSS feeds
- LLM (local via Ollama)
- Canva Bulk Create
- Logging & validation system
